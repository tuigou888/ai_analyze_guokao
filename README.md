# 行测研习

行测真题的本地数据整理与在线练习网站。题库涵盖 2016–2026 年公务员考试真题，网站支持筛选、练习、判分、错题复习与考点浏览。

**本项目默认把网站部署在单台服务器上，在线数据存于 SQLite。** Go 服务托管题目 API 与内嵌前端，宝塔面板可用 Nginx 提供反向代理和 HTTPS。服务器不需要 Node.js、PHP、MySQL、Python OCR 或本地大模型。

## 功能

- 按模块、年份、地区、考试类型和卷别筛选题目；中文关键词搜索题干和已有考点名。
- 从题库随机练习，或按原卷模块与题序组卷；支持保存草稿、判分与学习记录。
- 支持单选、多选、判断题和 A–H 等扩展选项；标准答案和解析在有效作答后显示。
- 错题自动收录，可收藏、订正、再次练习；考点页展示已有标注和个人作答统计。
- 个人中心提供四个页签，保存个人资料、目标和练习偏好，展示北京时间真实提交趋势、模块样本和 90 日活动；可续做、优先复练错题、管理登录会话并导出本人记录。
- 前端支持公式、材料和题图显示。管理入口独立于普通用户，可配置模型 API。
- v7 SQLite 迁移初始化用户、会话、练习记录、错题、考点映射和中文 FTS5 索引。

当前题库约有 27,449 道去重题目，源数据包含 58,890 次题目出现。现有标注约 550 道题；考点地图只展示有标注覆盖的真实数据，不代表已经完成全量蒸馏。

## 技术栈

| 部分     | 技术                                                |
| -------- | --------------------------------------------------- |
| 服务端   | Go 1.26.8 或更高安全补丁、Chi、SQLite（纯 Go 驱动） |
| 前端     | Vue 3、Vite、Vue Router、KaTeX                      |
| 反向代理 | 腾讯云服务器可使用宝塔面板管理 Nginx 与 HTTPS       |
| 部署方式 | Linux amd64 单二进制，前端静态文件嵌入二进制        |

Go 负责数据库迁移和服务启动。构建前端需要 Node.js 与 npm；生产服务器运行二进制时不需要 Node.js。

## 快速运行：已有题库

适合已有完整 `var/db/gk.sqlite`、`var/secret.key` 和 `data/90-图片/` 的开发环境。进入仓库根目录：

```bash
make web
make build
make admin-init        # 首次建管理员；已有管理员时跳过
make serve
```

浏览器打开：

- 普通用户：[http://127.0.0.1:8081/login](http://127.0.0.1:8081/login)
- 管理员：[http://127.0.0.1:8081/admin/login](http://127.0.0.1:8081/admin/login)

`make admin-init` 会交互式读取密码。管理员和普通用户使用不同账号体系。

## 首次运行：从原始数据建库

源题目数据是独立仓库，不包含在本项目的 Git 工作区中。新机器需要先准备 `data/`：

```bash
git clone https://github.com/ERRRC/xingcezhenti.git data
```

然后在仓库根目录执行：

```bash
make web
make reingest
make admin-init
make build
make serve
```

`make reingest` 从 `data/` 建库，**拒绝覆盖已有数据库及 WAL/SHM**。需要重新建题库时使用新路径，例如 `make reingest DB=var/db/gk-new.sqlite`；用户、练习和标注数据需要另行迁移，不能用新库直接替换线上库。新建库包含真题题干、选项和答案，但原始数据不含 OCR 回填结果；需要完整 P2 数据时应从已有库创建一致性快照，参见部署手册。

查看数据库概况：

```bash
make stats
```

## 前端热更新开发

已有数据库、图片目录和管理员之后，在仓库根目录开两个终端。终端一运行 Go API：

```bash
make serve
```

终端二运行 Vite：

```bash
cd web
npm ci
npm run dev
```

浏览器访问 [http://127.0.0.1:5173](http://127.0.0.1:5173)。Vite 将 `/api` 请求转发到 `127.0.0.1:8081`。修改 `web/src/` 后浏览器会热更新。

本地 Go 端口为 **8081**，Vite 为 **5173**；生产 systemd/Nginx 模板使用 **8080**。

## 生成 Linux 部署包

```bash
make release
```

默认生成 `var/gk-linux-amd64.tar.gz`，其中包含 Linux amd64 程序、服务配置、规范表和部署文档。压缩包**不包含**题库数据库、用户数据、图片和 `var/secret.key`，这些需根据部署手册单独准备。目标服务器若为 ARM64，请参见部署手册中的 ARM64 构建步骤。

## 重要数据位置

```text
var/db/gk.sqlite    SQLite 题库、用户、练习、错题、设置和蒸馏标注
var/secret.key     API Key 加密密钥；必须和数据库一起备份
var/runs/          蒸馏批次文件与归属记录
var/logs/          运行日志
data/90-图片/       本地题图和公式图；发布网站需要此目录
```

`var/` 与 `data/` 已被 Git 忽略。SQLite 使用 WAL 模式，备份正在运行的数据库时使用一致性快照，不要直接复制正在使用的 `.sqlite` 文件：

```bash
./var/gk backup --db var/db/gk.sqlite --bundle var/backups/gk-20261002
./var/gk backup --verify-bundle var/backups/gk-20261002
```

目标目录必须不存在；包含数据库、实际生效的密钥与完成标记，图片另行备份。`--out` 仅生成数据库快照。环境密钥模式需在备份进程提供实际 `GK_SECRET_KEY`，否则不能保证匹配。备份恢复、密钥迁移和线上定时备份见部署手册。

## 隐私与接口安全

- 题目查询与练习创建不返回标准答案、官方解析或题目推理链。
- `/api/questions/:id/reveal` 要求当前用户已经对这道题提交非空答案。
- 管理员会话与学习用户会话分开；管理密码和 API Key 不以明文存储。
- 面板端口与网站端口不同。线上 Go 服务只监听回环地址，由 Nginx 转发；不要将 8080 暴露到公网。
- 备份数据库时也要保存匹配的密钥文件；密钥丢失后无法解密已存的 API Key。

## 蒸馏

蒸馏管线与网站运行分开。按项目要求，先完成网站部署和验收，再参考 [P3 文档](docs/P3-INDEX.md) 在服务器手动配置、启动蒸馏。安装网站、启用宝塔反向代理、定时备份和运行普通练习都不会触发模型请求。

本轮修复增加 v9（选项 OCR 文本）和 v10（调用用量账本）迁移，启动前备份数据库与匹配密钥。提示词现为 v2，包含材料和选项 OCR；旧 v1 批次请使用新 `--run`，不能混合续跑。相同数据库、相同批次只允许一个执行器，锁由内核在进程退出时释放；历史未知消耗仍标记为统计缺口。
