# 行测研习前端改版参考包 · 使用说明

## 文件内容

- `行测研习-OpenCode-ClaudeCode-前端改版完整提示词.md`：工程改造指令，包含逐页面要求、约束、验收矩阵。必须优先阅读。
- `行测研习-页面布局参考.html`：可以在 Chrome/Edge 直接打开的纯本地静态原型；左侧导航可以切换 8 个页面示意，题库示例支持本地文本检索，高级筛选可展开，真题地区可切换。**不连接原站 API、不包含用户身份或真实密钥。**
- `参考截图/`：从本地参考 HTML 渲染得到的桌面/手机 PNG，供开发 Agent 做视觉对照，不能把示例数字和按钮逻辑写进正式生产环境。

## OpenCode / Claude Code 推荐使用方式

1. 解压到现有前端仓库的 `design-reference/` 文件夹（或任何独立目录）。
2. 将用户的 15 张原网站截图单独放在本地 `design-reference/original-screens/`；不要提交包含账号、邮件、密钥或其他隐私信息的截图到公开仓库。
3. 在项目根目录启动 OpenCode 或 Claude Code，并发送下方命令：

> 阅读 `design-reference/行测研习-OpenCode-ClaudeCode-前端改版完整提示词.md`，并以 `design-reference/行测研习-页面布局参考.html` 和 `design-reference/参考截图/` 作为视觉与布局参考。先审查仓库现有技术栈、路由、数据 API 和权限，再在不修改核心业务的前提下分阶段完成整站 UI 改造。请直接落地代码，运行已有构建与测试，并提交修改说明及逐页面验收结果。不要用假数据替代真实接口，也不要输出任何管理员 Cookie 或 API Key。

4. 尽量使用非生产环境验证修改，特别是用户管理、模型 API 设置、管理员账号、密码变更等操作。

## 参考属性与安全说明

参考 HTML 只是布局样例，不是可对接原项目的完整前端，也不能判断原站移动端、路由、后端 API 的运行状况。
例子中的题数、考点数、正确率、用户名称及试卷字段只是静态样例或来自用户提供的历史截图。正式版必须沿用现有真实数据。
所有密钥输入均为无效占位符。不要将用户历史会话 Cookie 用于客户端脚本或写入仓库。
