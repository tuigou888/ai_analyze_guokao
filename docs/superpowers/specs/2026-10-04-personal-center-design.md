# 个人中心：完整学习工作台设计规格

日期：2026-10-04。状态：用户已选择完整学习工作台，并于 2026-10-04 要求开始代码开发；按本文进入实现。

## 1. 目标与已确认范围

面向现有普通考生，将 `/account` 从改密页面扩展为个人学习工作台：能够管理资料和登录会话、设置学习偏好与备考目标、查看真实学习趋势，并从分析结果直接继续练习或复习错题。

用户已确认包含：资料/头像选择、改密与登录会话管理、学习偏好、个人记录导出；每日目标与考试倒计时；7/30/90 天趋势、六模块正确率画像、学习热力图；薄弱考点、错题复练、未完成练习续做和成就记录。

成功标准：功能实际保存并可跨登录恢复；全部学习数据来自本人已提交记录；图表有可理解的统计口径和空状态；推荐能创建有效练习；新功能不破坏既有认证、草稿版本锁、交卷幂等及备份恢复。

## 2. 现有实现与约束

- 后端为 Go + Chi + modernc SQLite，业务集中于 `internal/study`，HTTP 位于 `internal/serve`。
- 前端为 Vue 3 + Vue Router + Vite，现有账户页为 `web/src/views/Account.vue`，记录页为 `Records.vue`。
- `app_user` 已有用户名、昵称、注册/最后登录时间；`app_session` 只有 token 摘要、用户与过期时间，没有设备信息。
- `practice_session`、`practice_answer`、`wrongbook`、`favorite`、`user_concept_stat` 已提供实际练习、错题、收藏与考点数据。
- 当前迁移到 v11，草稿写入必须携带 `draft_revision`；新增迁移只追加，保留旧版本条目。
- 当前真实题库有六个模块：政治理论、常识判断、言语理解与表达、数量关系、判断推理、资料分析。考点标注仅覆盖 550 道题，不能把已有标签当作全量诊断。
- 继续保持普通用户与管理员分离；本轮所有验收写入临时库，不操作正式数据库、密钥或远程服务。

## 3. 页面与交互

保留 `/account`，将导航名称和页面标题改为“个人中心”，顶部用户资料入口可以直达。保留现有蓝白界面、桌面侧栏和移动端布局。

个人中心采用四个本地切换页签，不通过修改路由 query 重建表单：

| 页签 | 内容 |
|---|---|
| 学习总览 | 资料摘要、考试倒计时、今日目标、期间统计、趋势图、模块画像、热力图、成就 |
| 复习助手 | 未完成练习、重复错题、薄弱模块与考点、收藏和学习记录入口 |
| 资料与偏好 | 昵称、简介、预置头像、目标、考试信息、默认题量/模块、练习字号、CSV 导出 |
| 账户安全 | 原密码校验改密、当前会话、其他登录会话、单独撤销和退出其他会话 |

加载、保存、失败、冲突和空数据均有明确状态。表单有未保存修改时，切换页签或离开页面提供保存/放弃保护；保存过程中不允许重复提交。409 时保留输入，提供明确确认后的重新加载，不能更新版本后自动重发旧输入。

图表可以通过按钮选择 7/30/90 天，鼠标与键盘均能查看具体值，并提供文字摘要/数据表。375px 下无整页横向溢出；热力图在自身容器内滚动。颜色同时配合数值、标签和形状表达状态。

## 4. 通用功能

### 4.1 资料与头像

- 用户名只读；昵称保持最多 40 个 Unicode 字符；简介最多 200 字。
- 提供 8 种预置头像样式，使用受控编号和用户昵称首字；不接受头像 URL 或任意 HTML。
- 展示注册日期，昵称与头像保存后同步至顶部用户区；旧用户默认沿用原昵称和默认头像。
- 本轮头像为选择预置样式，不新增文件上传服务、存储配置或图片处理依赖。

### 4.2 学习偏好

- 默认练习题量：10、20、50，默认 20。
- 默认练习模块：全部或题库实际存在的模块，默认全部；URL 显式筛选优先于用户偏好。
- 练习正文字号：标准 16px、舒适 18px、大字 20px，默认 16px；作用于练习题干/解析，不改变整站控件字号。
- 服务端保存并跨设备读取；登出和切换账号清理客户端缓存，避免沿用其他人的偏好。

### 4.3 目标与考试信息

- 每日作答目标：5–200 次，默认 20；每日练习时长目标：5–180 分钟，默认 30。
- 可选考试名称最多 40 字，考试日期为北京时间的未来日期，最多设置到五年后；日期为空时不显示倒计时。已存日期在时间推移后过期，可保持原值编辑其他资料；新设置或修改的日期仍须符合未来日期限制。
- 显示今日实际完成量、剩余量及进度；进度条最大为 100%，同时显示超额完成数值。
- 日期过后显示“考试日期已到/已过”，不显示负倒计时或自动删除设置。

### 4.4 会话安全

- 保留现有改密原密码校验和全部旧会话撤销规则，原密码错误仍为 400。
- 展示活跃登录会话：当前标识、浏览器/操作系统类别、登录时间、过期时间和脱敏来源地址。
- 新登录采集受限元数据；来源使用已有可信代理 `clientIP` 解析规则，不信任任意 X-Forwarded-For。
- IP 在存储前脱敏：IPv4 保留前三段、IPv6 保留 /48 前缀；不做外部 IP 地理查询。
- 旧会话缺失元数据时显示“历史会话/信息未知”，不编造设备和登录时间。
- 会话使用独立随机公开 ID 供管理；API 不返回原始 token 或 token 摘要。列表每页 20 条。
- 可撤销本人某个其他会话；撤销其他用户会话返回 404。当前会话退出继续调用现有 logout。
- “退出其他会话”需界面确认，保留当前 Cookie 对应的会话；此功能不会创建新的登录凭据。

### 4.5 导出

- 导出本人已提交练习的 CSV，范围可选 7/30/90 天或全部，默认 30 天。
- 每行一条作答记录：提交时间、练习类型、练习 ID、题号、模块、本人答案、是否正确、记录耗时。
- 不导出密码、会话、密钥、别人的记录、题目解析或未提交草稿。
- UTF-8 CSV 带 BOM，规范转义逗号/换行/引号，并处理电子表格公式注入前缀。
- 单次最多 5,000 条；超出时返回 400，提示缩小范围，不静默截断。输出文件名由服务器固定格式生成。

## 5. 数据口径与可视化

### 5.1 统一口径

统计时区固定为 `Asia/Shanghai`，接口返回 `timezone` 和统计起止日期。日期范围包含今天，按北京时间自然日计数；7 天表示今天及前六天。

- 仅统计 `submitted_at IS NOT NULL` 的练习；草稿不计学习成果。
- 作答次数为非空 `user_answer` 的记录数，重复练习同题按多次作答计算；它不是去重题量。
- 作答正确率为正确次数 / 非空作答次数，分母为 0 时返回 null，并显示“暂无作答”。
- 完成练习数为已提交 session 数；答题时间使用该 session 的 `duration_ms`，避免 joins 重复累加。
- 今日目标、活动日与趋势按提交时间归属日期；跨午夜提交的同一练习整体归于提交日。
- 记录时长来自现有客户端计时，不表示在线停留时长，也不作为正式考试监考成绩。
- 正确率图缺少作答的日期为 null，不画为 0%；作答量热力图无活动日为 0。

概览同时区分累计统计与所选期间统计。期间比较采用前一个等长区间；上期为 0 时显示绝对增量，不生成无穷百分比。

### 5.2 图表

| 图表 | 维度与交互 |
|---|---|
| 作答趋势 | 每日作答次数和正确率，两张关联小图分别表达单位，支持 7/30/90 天与焦点查看 |
| 六模块画像 | 各模块正确率、样本数及作答量；无样本明确空缺，不能当作 0 分，少于 5 次标为样本不足 |
| 学习热力图 | 固定最近 90 天每日作答量；支持查看具体日期、次数与记录时长 |
| 今日目标 | 作答和分钟双进度环，显示具体分子/分母；支持进入目标设置 |

使用 Vue + 原生 SVG/CSS 实现这些有限图形，暂不引入新的图表包。将趋势、模块画像、热力图、进度图拆成独立组件，提供 accessible name、文字摘要和可展开数据表；数据由统一 dashboard DTO 提供。

### 5.3 连续练习与成就

连续练习以完成至少一次非空作答的提交日计数。今日尚未练习但昨日有练习时，保留截至昨日的连续天数并提示“今天继续”；今天和昨天都无活动时当前连续天数为 0。最长连续天数依据全部个人历史计算。

成就实时由本人数据推导，不允许客户端直接写入解锁状态：首次非空提交、累计 100 次/1,000 次作答、连续 7/30 天练习、六模块各完成至少 5 次作答。显示明确解锁条件与进度；名称使用“作答次数”，不误称去重题数。不增加兑换、排名或奖励发放系统。

## 6. 项目特色：复习助手

- **续做**：最近 3 份未提交练习，显示类型、题量、已保存作答数，进入原 session 保留草稿版本保护；查看更多进入记录页。
- **错题优先**：从本人待订正自动错题中按累计错次数降序、最近答错时间降序选择最多 20 道，创建现有 wrongbook 练习；没有待订正题时显示完成状态。
- **薄弱模块**：在所选期间作答至少 5 次的模块中，按正确率从低到高列最多 3 个，显示样本数并可开始对应模块练习；不足时建议补充样本。
- **薄弱考点**：依据本人已提交记录和最新标签映射计算，至少 5 次作答才参与排序；展示最多 3 个并进入现有 concept 练习。标明统计期内已标注作答占比和标注覆盖限制。尚未形成稳定考点映射的标签仍计入覆盖，但不生成不可操作的考点建议，提示先做模块练习。
- 收藏数、待订正错题数和历史记录入口保持现有业务规则。手工标记 resolved 不被宣传为“真实复练答对率”。
- 推荐为透明的规则计算，界面使用“复习建议/已有标注”，不以在线 AI 诊断名义展示或调用付费模型。

## 7. 数据结构与职责

追加 v12：

1. `user_profile`：`user_id` 主键/FK、`bio`、`avatar_id`、`daily_questions`、`daily_minutes`、`exam_name`、`exam_date`、`default_limit`、`default_module`、`reading_size`、`revision`、`updated_at`。昵称继续存于 `app_user.nickname`，保持单一来源。
2. 回填现有用户的默认 profile，注册新用户时保证 profile 创建原子性。GET 不通过隐式写入建立默认资料。
3. `app_session` 追加随机 `public_id`、可空 `created_at`、`device_label`、`ip_hint`；旧行回填 public_id，新建唯一索引，不修改已有 token 摘要和过期时间。
4. 为期间统计增加 `practice_session(user_id,submitted_at)` 索引，为活跃会话管理增加适当用户索引。

`internal/study/profile.go` 负责资料/偏好/目标与版本校验；`dashboard.go` 负责统计、活动日、成就和规则推荐；`sessions.go` 负责会话列表/撤销；`export.go` 负责可导出的业务记录。HTTP 层仅鉴权、校验请求、调用业务和输出响应，不嵌入统计 SQL。

资料整体保存使用 revision 乐观锁，并在事务中更新昵称和 profile；并发旧版本返回 409。新写入复用 `store.WriteTx`；保持交卷原子性和幂等。看板采用短的只读一致性事务，明确使用 ReadOnly 选项以避免 `_txlock=immediate` 把分析查询变成写锁持有者。查询按当前用户与时间窗口过滤，响应有界，不每个日期单独请求数据库。

不增加缓存、队列或后台聚合依赖；统计性能在合成历史验收后决定是否需要后续预聚合。统计正确性不依赖浏览器缓存。

## 8. API 合同

新增路由全部位于 requireUser 组内：

| 方法/路径 | 合同 |
|---|---|
| GET `/api/account/profile` | 本人资料、偏好、目标、revision、注册日期；无行时由兼容读取返回默认值 |
| PUT `/api/account/profile` | 完整可编辑字段 + revision；400 参数错误，409 陈旧版本；返回保存后的资料 |
| GET `/api/account/dashboard?days=30` | days 仅 7/30/90；返回范围、累计/期间/今日计数、趋势、模块、90 日活动、连续天数、成就与复习建议 |
| GET `/api/account/sessions?page=1` | 本人活跃会话，每页 20，含当前标识和 total；不暴露凭据 |
| DELETE `/api/account/sessions/{public_id}` | 撤销本人其他会话，未找到/他人 ID 为 404，当前会话为 400 |
| POST `/api/account/sessions/revoke-others` | 撤销除当前 Cookie 外的本人会话，返回撤销数量 |
| POST `/api/account/review/wrongbook` | 服务端选择本人高频待订正错题，复用 CreateSession，返回新练习；无候选时 400 + 可理解提示 |
| GET `/api/account/export?days=30` | days 仅 7/30/90/all；本人 CSV；超过上限 400，不静默截断 |

薄弱模块、考点练习和续做通过已有 `/api/practice/sessions` 与 GET session 合同完成，不新建另一套判分流程。原 `/api/auth/*` 继续兼容。登录元数据通过新的内部方法或可兼容参数传入，已有 service 登录测试/调用不丢失密码 hash 的 CAS 保护。

## 9. 安全、兼容与异常

- 用户身份完全由已验证 Cookie 决定，客户端 user_id 不参与数据查询；管理员 Cookie 不可进入普通用户个人中心。
- 写接口复用完整 Origin 和 application/json 检查；DELETE 无 body 的请求仍执行 Origin 检查。
- profile 使用字段白名单与长度/数值枚举检查，界面内容通过 Vue 文本渲染；头像编号及字号不可注入任意 CSS。
- 列表、导出和推荐保留用户隔离；不存在和其他用户的对象 ID 使用相同 404，不泄漏私有数据。
- 不修改草稿协议、不清空题库/练习、不把普通用户设置写入全局 `setting` 表。
- 500 为异常；写入容量不足沿用 503/Retry-After；401 仅表示身份失效，400/409 不触发误登出。
- 无数据返回空集合、null 正确率和默认 profile，不用示例成绩填图。单个图形异常不得使整页白屏。
- 修改密码和会话撤销后，浏览器/其他设备的过期身份按现有逻辑回登录；修改资料不会撤销登录。
- CSV 下载复用浏览器同源凭据，不把 token 放入 URL、文件名或导出内容。
- v12 回滚前备份数据库和有效密钥；发布包含前端的新二进制，先在副本验证迁移与完整备份恢复。
