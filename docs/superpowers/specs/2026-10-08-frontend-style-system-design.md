# 全站前端公共样式体系设计规格

日期：2026-10-08。状态：待用户审阅。

## 1. 目标与成功标准

为 Vue 前端建立可复用、可检查的样式标准，避免页面分别定义控件、按钮、卡片、提示框、颜色、字号、间距和圆角。保留页面真正不同的内容布局与图表表达；页面级样式不得重新定义公共组件的视觉标准。

成功标准：

- 全站使用同一组语义颜色、字体角色、间距、圆角、边框、焦点和控件尺寸 tokens。
- 按钮、表单控件、表单字段、卡片/面板、提示框、标签、分页和数据表的共有外观只在公共组件样式中定义。
- 页面和功能样式只负责布局、断点、内容密度以及专属图表/数据状态，并引用公共 tokens。
- 设置页、个人中心不再各自覆盖公共按钮、卡片、提示框、控件或错误状态。
- 不改变页面内容、交互、业务逻辑和用户可调的练习字号。

## 2. 当前结构与问题

- 前端包含约 30 个 Vue 页面与组件。普通页面样式集中在 `web/src/style.css`，个人中心样式位于 `web/src/components/account/account.css`，唯一的 Vue scoped 样式块在 `web/src/views/Settings.vue`。
- 全局样式同时放置基础元素、按钮/表单/提示框等公共规则，以及题库、练习、考点、试卷、登录和记录页布局；文件压缩为少数长行，难以检查覆盖关系。
- `Settings.vue` scoped 样式重复定义 `.card`、`button`、`button.primary` 和 `.notice`；个人中心通过 `.pc-card` 另行设置卡片表面和尺寸。
- 语义颜色 token 已有一部分，但相同品牌/状态颜色也以字面量出现；字号、间距和圆角值混用。全局断点为 1180/860/580px，个人中心还有 1100/600px 断点。
- 五处动态 `:style` 用于学习进度、图表数据或用户选择的阅读字号。这些是数据/偏好值，不属于页面自定义视觉标准。
- 上一轮已在工作区开始统一表单控件；新设计需保留这项改动，并将其纳入正式公共控件样式。

## 3. 设计决策

### 3.1 采用 CSS 设计体系，不引入 UI 框架

保留 Vue、Vite 和现有模板结构，不添加 UI 库、Tailwind 或构建插件。通过共享 tokens 与语义组件类统一标准，避免为样式整理引入新的依赖和大范围模板迁移。

### 3.2 样式分层与文件职责

新增 `web/src/styles/`，按以下顺序加载：

1. `tokens.css`：颜色、文字、间距、圆角、边框、焦点和控件尺寸等设计变量。
2. `base.css`：重置、正文、标题、链接、键盘焦点和原生元素基线。
3. `components.css`：按钮、表单字段、卡片/面板、提示框、标签、tabs、分页和表格等公共组件视觉。
4. `layout.css`：应用外壳、导航、内容容器等跨页面布局。
5. `pages.css`：题库、练习、考点、试卷、记录、登录和管理页的布局与响应式规则。

个人中心继续由独立 feature 样式承载图表、热力图和个人中心专属布局；其共享视觉值迁入公共 tokens/components。样式文件采用可读的多行 CSS，按职责分块并使用明确的组件命名，不继续扩展单行压缩样式。

### 3.3 公共 tokens

沿用当前蓝白视觉方向，先定义语义变量，再逐步把重复字面量映射到变量：

- 颜色：页面背景、表面、弱化表面、正文、次级文字、边框、品牌主色、主色弱背景、成功、警告、错误、信息、图表系列。
- 字体角色：正文、辅助文字/说明、标签、控件、标题层级、等宽数据。
- 间距刻度：4、8、12、16、24、32、40、48px；组件和页面从这些值组合。
- 圆角：小型标记、控件/按钮、卡片/面板、圆形头像等语义级别。
- 组件尺寸：控件高度、按钮最小高度、边框宽度、焦点环和过渡时长。

颜色由语义而非页面命名，例如 `--color-surface`、`--color-border`、`--color-primary`、`--color-danger`。不为每个页面创建一套同义 token。

### 3.4 公共组件和页面边界

公共组件样式统一视觉属性，页面样式保留几何关系：

- 控件：文字输入、数字/日期、密码、select、textarea、placeholder、hover、focus-visible、disabled、readonly、`aria-invalid`。
- 按钮：基础按钮、primary、secondary/ghost、text、disabled；页面可决定按钮排列和宽度，不得重定义全站按钮边框、字号和圆角。
- 表面：统一卡片/面板的背景、边框、圆角和默认间距，支持明确的紧凑/宽松变体；现有 `.panel`、`.card`、`.pc-card` 的重复外观映射至共用规则。
- 状态：统一 `.notice` 的信息/成功/警告/错误颜色、边框、字号和内边距；位置和相邻布局由容器决定。
- 其他：标签、tabs、分页和数据表若有跨页面共性，使用同一组件类与状态变量。
- 字段：统一标签、控件、说明、错误提示的垂直节奏；现有语义 `<label>` 和 ARIA 关系保留。

页面/feature 样式只设置 grid/flex、区域顺序、内容宽度、图表尺寸、响应式折叠和业务数据状态。不同页面可采用不同结构和密度，但这些差异必须由公共组件变体与 tokens 表达，不能复制一套基础外观。

### 3.5 断点与动态样式

跨页面采用统一断点：1180px（宽布局收缩）、860px（导航/主要列折叠）、580px（小屏）。确有内容宽度理由的图表断点可以单独保留，并需在 feature 样式注明原因。

数据图形的动态宽度、所选阅读字号和状态值仍由 Vue 运行时设置；其静态颜色、圆角、线宽和状态外观使用公共变量。阅读字号只影响题干/解析，不改全站控件尺度。

## 4. 迁移范围

- 把现有 `style.css` 拆分为上述公共层和页面布局层，保留现有类名或通过一次性映射完成迁移，避免改变路由和 DOM 语义。
- 移除 `Settings.vue` scoped 样式对按钮、卡片、提示框和控件的通用外观定义；仅保留设置表单网格、表格列等独有布局。
- 将 `.pc-card` 的表面样式映射到公共卡片规则；个人中心图表和组件间距继续属于 feature 布局。
- 将公共语义颜色与间距中的重复硬编码迁移到 tokens；数据状态颜色只保留语义明确的变量，不做无意义的统一替换。
- 全量检查 `web/src` 中 CSS、scoped styles、inline styles 和 Vue 模板，确保没有遗漏其他页面的通用控件规则。

## 5. 非目标

- 不重做任何页面的视觉设计，不统一各页信息布局或内容密度。
- 不改 Vue 组件关系、API、路由、交互、文案或数据行为。
- 不迁移到 UI 组件库、CSS-in-JS、utility-first 框架或 CSS 预处理器。
- 不移除按用户偏好变化的阅读字号和按数据变化的图表/进度值。

## 6. 风险与处理

- CSS 拆分会改变加载顺序和层叠结果。先固定导入顺序，再迁移公共样式；清理通用元素选择器覆盖，避免靠提高 specificity 或 `!important` 维持旧外观。
- 当前 CSS 有长行和旧色值，机械全局替换可能影响状态语义。先映射 tokens，再逐段迁移并检查差异。
- 个人中心包含热力图、SVG 图表和移动端内滚动，这些属于独有布局；迁移公共视觉时不得改动其数据表达和滚动边界。
- 仅支持现有浅色主题，本次不新增暗色模式。

## 7. 验收

- 全站共享视觉属性可从 tokens/components 找到单一来源；页面/feature 样式没有通用 `button`、表单控件、卡片/提示框外观重复定义。
- 题库筛选、登录、管理设置、设置表单、个人资料、安全表单和个人中心图表选择器统一显示输入控件样式。
- 主按钮、次级按钮、卡片/面板、提示状态、标签和分页视觉一致，disabled、focus-visible、error 状态清晰。
- 练习、题库、考点、试卷、记录、登录、设置、管理和个人中心的专属布局及数据可视化仍可用；小屏下布局按共享断点收缩。
- `npm run build` 成功，`git diff --check` 无错误；源码检索确认通用样式无页面重复定义。
- 浏览器可用时检查桌面及 375px 视口的登录、筛选、设置和个人中心；若环境没有浏览器，明确记录该限制，不把静态构建说成视觉验收。

## 8. 实施顺序

1. 按本规格创建 tokens、base、components、layout 和 pages 样式层，确定统一导入顺序。
2. 迁移通用控件、按钮、卡片、提示框、标签、分页和表格规则，并移除设置页及个人中心的通用重复定义。
3. 将跨页重复值映射到 tokens，保留并整理页面/feature 布局和图表状态规则。
4. 对全部 Vue/CSS 文件做覆盖审计，完成构建、差异检查和可用的浏览器视口检查。

用户审阅并批准本规格后，再编写包含具体文件改动和验证命令的实施计划。
