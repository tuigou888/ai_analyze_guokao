# 个人中心界面实现指导

主体是正在备考的普通考生；页面的工作是回答“今天完成了什么、接下来练什么”，并提供真实资料和安全管理。沿用项目既有蓝白研习风格，不另造整站视觉体系。

- 颜色沿用 `--accent #215eac`、`--text #20324b`、`--panel #fff`、`--bg #f2f5f9`、`--ok #167052`，目标/连续练习用少量暖色 `--warn #8b590d`。
- 标题使用项目已有中文字体栈，考生问候与考试信息可局部使用宋体显示，数值使用 `--mono` 与 tabular-nums；不加载远程字体。
- 上方为头像、昵称、注册信息和考试倒计时，紧接四页签。总览以“今日双目标”作为学习行动入口；趋势与六模块画像中部并列，活动日历和成就作为下方复盘。
- 特色元素是可聚焦的90日学习日历：每一天对应真实作答活动，选择后显示次数和记录时长。它与今日目标、连续练习、复习建议共享同一份真实数据口径。
- 空数据图显示坐标/结构与开始练习入口；正确率为空不落到零分。少样本与稀疏标签用真实说明。头像为8个受控色样式，不引入任意CSS值。
- 页面表单/图表/会话按组件拆分；独立CSS使用 account/pc 前缀，不覆盖所有 `.panel`、`button` 或 `.option`。
- 图表有鼠标和键盘选择、文字摘要与折叠数据表。热力图避免90个无谓连续tab目标，使用方向键或日期选择器；375px整页不溢出，图表数据表可局部滚动。
- 加载失败有重试；范围切换过快忽略旧响应。所有“保存成功”必须对应实际服务器版本；409保留输入，未保存表单切换/离开保护。

已参考 frontend-design 的主题化、克制和层级指导，以及 ui-ux-pro-max 的 Empty States / Keyboard Navigation 条目。公开搜索只使用通用界面关键词，没有发送项目数据。

实际接口接入注意：accuracy为0–100/null；目标和趋势duration用today/period/trend中的session.duration_ms，不能累加modules中的答案耗时或模块sessions。review含unmapped_labeled_answered提示未形成映射的标签，仅weak_concepts的有效concept_id可启动考点练习。资料编辑允许保持本人已存过期考试日期，不用HTML未来min阻止改昵称；新选择/变更日期才做未来限制。
