# 个人中心

普通考生登录后，从顶部资料入口或侧栏“个人中心”进入 `/account`。四个页签切换使用本地状态。资料、偏好和目标保存在本人账户，刷新或重新登录后恢复。

| 页签 | 用法 |
|---|---|
| 学习总览 | 查看今日作答/分钟目标、考试倒计时、累计与期间统计、趋势、模块样本、90 日活动、连续练习和成就；期间可选 7/30/90 天 |
| 复习助手 | 续做最近三份练习；按累计错数优先复练待订正自动错题；从有足够样本的模块/考点开始练习；进入收藏和历史记录 |
| 资料与偏好 | 编辑昵称、简介、八种头像、目标、考试信息、默认题量/模块和练习字号；下载本人已提交 CSV |
| 账户安全 | 用原密码改密；查看本人登录会话，确认撤销其他会话或退出其他设备；退出当前账户和重算统计 |

资料用户名和注册日期只读，昵称/简介最多 40/200 字，考试名称最多 40 字。每日目标为 5–200 次及 5–180 分钟，默认 20 次/30 分钟。默认题量可选 10/20/50（初始 20），模块初始全部；题库 URL 中明确的筛选优先。字号 16/18/20px 仅作用于练习正文、选项和解析。退出或换账号清理客户端偏好。

考试日期可为空；新日期必须是北京时间未来日期，最多五年后。已存日期到期后显示“已到/已过”，不会变为负倒计时或被自动删除，也可保留日期修改其他资料。目标进度最高显示 100%，实际超额数量仍显示。

保存包含资料版本。其他窗口先保存时，本次收到 409 会保留输入；确认重新加载后再编辑保存。页面不会自动重发旧版本。成功保存同步顶部昵称/头像和偏好，同账号迟到的旧资料响应不会让已确认版本倒退。未保存输入离开页面、换页签或退出时有保护；保存等待中阻止重复保存和离开。400/409 不表示身份失效。

同一浏览器另一标签退出或换账号时，旧页面提示“登录账户已变化”，保留尚未保存的资料/密码输入。请先记录输入，再点“重新进入个人中心”读取当前登录账号。旧页资料保存/重载、CSV、安全操作和退出都不能把操作套到新账号；没有及时收到通知时，服务器也会拒绝账号不符的请求。账号变化的 409 与同账号资料版本冲突分开处理，不提供自动覆盖或直接重发。新页面退出会撤销服务器会话并清理本地身份，响应不删除浏览器 Cookie，避免迟到的旧账号退出响应影响后来登录的账号；残留 Cookie 已不能认证，会在过期或再次登录时替换。

## 统计口径

- 时间固定为 Asia/Shanghai；7 天包含今天和前六天，30/90 同理。活动、趋势、今日目标均按提交日归属，跨午夜练习整体属于交卷当天。
- 只有已提交练习计成果。非空答案计一次作答，同题复练按多次计算；空答案不计作答或正确。零分母正确率为空并显示“暂无作答”，不能当作 0%。
- 完成练习数是提交会话数。总时长使用会话记录的 duration_ms，避免因答案 join 重复累加；它是客户端记录时长，不是在线停留或监考成绩。模块时长只汇总该模块有效答案耗时，跨模块会话的模块 session 数不能相加当总量。
- 累计统计与选定期间分别展示。上期为紧邻等长区间；上期为零时显示绝对增量。活动日须至少有一次非空提交；今日未练而昨天练过时保留昨天结束的连续天数，最长连续依据全部历史。
- 模块/考点少于五次显示样本不足，不参与薄弱建议。六个核心模块都有明确样本数，无记录不表示 0 分。建议最多三项；错题优先练习最多二十道，按错数、最近错时排序，仍使用原草稿和交卷协议。
- 考点依据当前已有最新标签；覆盖率是期间已标注作答占比，不是全题库诊断。缺稳定映射的标签计覆盖但不生成无法练习的考点；可先做模块练习。手工订正不等于复练真实答对率。
- 成就从本人记录实时计算：首次作答、累计 100/1,000 次、连续 7/30 天、六核心模块各五次，不提供排名、兑换或付费 AI。

趋势次数与正确率分图表达；模块画像、学习日历、目标环均有数值摘要和可展开数据表。图表支持键盘查看值；日历用方向键/Home/End 查看具体日期，375px 下日历与数据表在自己的容器内滚动。无数据保持空状态，读取失败可重试。

## 会话与导出

活跃会话每页二十条，显示当前标识、设备类别、登录/到期时间和脱敏来源。旧会话缺信息显示未知；IP 在存储前脱敏（IPv4 前三段，IPv6 /48），不进行外部定位。撤销其他设备不会退出当前 Cookie；改密继续撤销全部旧会话。普通用户和管理员入口独立。

CSV 可选 7/30/90 天或全部，默认三十天；带 UTF-8 BOM，列为提交时间、类型、练习 ID、题号、模块、本人答案、正确与记录耗时。规范转义并处理公式注入前缀；仅本人已提交记录（包括提交中的空答案），不含解析、草稿、凭据或其他用户数据。单次最多 5,000 行，超限整体拒绝并提示缩小范围。浏览器使用同源 Cookie 下载，不把凭据放入 URL。

## 升级与验证

v12 为追加迁移，回填旧账户默认资料和独立公开会话 ID，保留密码、登录摘要、草稿版本和历史提交。升级前生成并验证完整数据库与有效密钥 bundle，在副本验证新程序；回滚需恢复升级前数据库、匹配密钥与旧程序。步骤见 [部署手册](deployment-2c4g.md)，接口见 [API 文档](api-design.md)，本地集成证据与未测边界见 [Task4 记录](personal-center-task4-report.md) 和 [最终修复记录](personal-center-final-fix-report.md)。
